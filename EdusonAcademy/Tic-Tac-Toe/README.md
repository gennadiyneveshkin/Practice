## Условия задания
Разработайте игру «Крестики-нолики», которая которая запускается из командной строки или терминала IDE. Игра должна работать следующим образом: 
1. Программа отрисовывает игровое поле размером 3х3. 
2. Программа спрашивает, за какую сторону будет играть пользователь — крестик или нолик, а также принимает координаты клетки, в которую игрок хочет поставить символ.
3. Программа проверяет, занята ли та клетка, координаты которой ввел игрок. Если да, предлагает ему ввести другие.
4. Если клетка, координаты которой вводит игрок, свободна, программа ставит символ в эту клетку и заново отрисовывает поле.
5. Каждый ход программа проверяет, не стал ли он выигрышным. Если стал, сообщает об этом игроку, после чего игра заканчивается.
6. Также игра заканчивается, если на поле не осталось свободных клеток, при этом нигде нет полного ряда крестиков или ноликов. В таком случае результат игры — ничья.  
7. Когда игра закончилась, программа спрашивает игроков, не хотят ли они сыграть еще раз.
8. Программа раскрашивает клетки поля в разные цвета в зависимости от того, что находится в клетке: крестик, нолик или ничего из этого.

### Шаг 3. Разделите запрос координат и ход игры на две функции
Перепишите функцию `ask_and_make_move(player, board)` через две функции:

- `make_move(player, board, x, y)`, которая непосредственно делает ход.  

Функция `ask_and_make_move` принимает на вход двумерный список `board` и игрока `(Х или 0)`. Она вызывает `ask_move`, чтобы попросить игрока ввести координаты той клетки, на которой он хочет разместить свой символ. Когда ход сделан, функция `ask_and_make_move` вызывает функцию `make_move`, которая выполняет ход на клетку, координаты которой программа только что получила.  

Если место уже занято, функция предлагает игроку повторить попытку.

```python
def ask_move(player, board):
    # дать игроку возможность сделать ход, то есть ввести координаты
    x, y = input(f"{player}, enter x and y coordinates (e.g. 0 0): ").strip().split()

    x, y = int(x), int(y) 
    # задать условие, которое проверяет, свободно ли место
    if (0 <= x <= 2) and (0 <= y <= 2) and (board[x][y] == " "):

        return (x, y)
    else:
        print("Клетка занята. Введите координаты еще раз.")
        return ask_move(player, board)
```

### Шаг 4. Напишите функцию, которая отследит выигрышный ход
Напишите функцию `check_win(player, board)`, которая проверит, не стал ли очередной ход выигрышным. Она принимает текущего игрока и доску в качестве входных данных. Затем функция проверяет, совпадают ли все символы в строке, столбце или диагонали. Если совпадают, то игрок выиграл и возвращается `True`. Если не совпадают, возвращается `False`.

<details>
    <summary><strong>Как это сделать</strong></summary>
    
Изучите пример кода функции `check_win(player, board)`.

```python
def check_win(player, board):
    # проверить, совпадают ли значения в строках и столбцах
    for i in range(3):
        # проверить, совпадают ли значения в строках
        if board[i] == [player, player, player]:
            return True
        # проверить, совпадают ли значения в столбцах
        if board[0][i] == player and board[1][i] == player and board[2][i] == player:
            return True
    # проверить, совпадают ли значения на диагонали из верхнего левого в нижний правый угол
    if board[0][0] == player and board[1][1] == player and board[2][2] == player:
        return True
    # проверить, совпадают ли значения на диагонали из верхнего правого в нижний левый угол
    if board[0][2] == player and board[1][1] == player and board[2][0] == player:
        return True
    return False
```

### Шаг 5. Напишите функцию, которая управляет игрой
Напишите основную функцию `tic_tac_toe()`, которая будет управлять ходом игры. Она выполняет действия в таком порядке: 
1. Вызывает функцию `draw_board(board)` и запускает игровой цикл. В каждой итерации цикла функция `tic_tac_toe()` вызывает функцию `ask_and_make_move(player, board)`, которая просит игрока поместить свой символ на доску.
2. Вызывает функцию `check_win(player, board)`, чтобы проверить, выиграл ли игрок.
3. Если игрок выиграл или на доске больше нет свободных мест, игра заканчивается. В таком случае функция спрашивает игроков, хотят ли они сыграть снова.

<details>
    <summary><strong>Как это сделать</strong></summary>
    
Изучите пример кода функции `tic_tac_toe()`.

```python
def tic_tac_toe():
    # задать бесконечненый цикл, который проводит игры
    while True:
        board = [[" " for i in range(3)] for j in range(3)]
        player = "X"
        # задать бесконечнный цикл, который проводит конкретную игру
        while True:
            # нарисовать игровое поле
            draw_board(board)
            # запросить ход
            ask_and_make_move(player, board)
            # проверить, выиграл ли игрок
            if check_win(player, board):
                print(f"{player} выиграли!")
                break
            # проверить, произошла ли ничья
            tie_game = False
            for row in board:
                for cell in row:
                    if cell == " ":
                        tie_game = True
            # если произошла ничья, завершить цикл
            if not tie_game:
                break
            player = "O" if player == "X" else "X"
        # спросить игроков, хотят ли они сыграть еще нраз
        restart = input("Хотите сыграть еще раз? (y/n) ")
        if restart.lower() != "y":
            break
```
