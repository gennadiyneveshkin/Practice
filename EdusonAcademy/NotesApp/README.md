## Условия задания
Разработайте приложение для заметок. Оно должно работать следующим образом:
1. Приложение позволяет создавать, удалять и редактировать заметки по запросу пользователя. У каждой заметки есть название и текст внутри. 
2. По умолчанию приложение выводит все заметки пользователя в порядке от самой короткой до самой длинной. 
3. Дополнительно в приложении есть возможность отсортировать все заметки пользователя от самой длинной до самой короткой.
4. Приложение обрабатывает ошибки, то есть оно отказоустойчивое. Если пользовательский ввод неверный, приложение сообщает об этом пользователю.

Создайте функции для каждой операции с заметками, а также общую функцию, которая управляет работой приложения.

## Ход решения
### Шаг 1. Создайте новый python-файл для приложения
Создайте новый файл и организуйте проект для разработки приложения.

### Шаг 2. Напишите функцию, которая создает заметку 
Напишите функцию `build_note` с аргументами `note_text` и `note_name`. Она получает название и текст заметки, а затем создает текстовый файл с этим названием и текстом. 
<details>
    <summary><strong>Как это сделать</strong></summary>
    
Изучите пример кода функции `build_note`.

```python
def build_note(note_text, note_name):
    with open(f"{note_name}.txt", "w", encoding="utf-8") as file:
        file.write(note_text)
    print(f"Заметка {note_name} создана.")
```
    
</details>

### Шаг 3. Напишите функцию, которая запрашивает название и текст заметки у пользователя, после чего создает заметку
Напишите функцию `create_note()`. Она запрашивает у пользователя название и текст заметки, а затем вызывает функцию `build_note(note_text, note_name)`.

<details>
    <summary><strong>Как это сделать</strong></summary>
    
Изучите пример кода функции `create_note()`.

```python
def create_note():
    note_name = input("Введите название заметки: ")
    note_text = input("Введите текст заметки: ")
    build_note(note_text, note_name)
```

</details>

### Шаг 4. Напишите функцию, которая выводит заметку по запросу пользователя
Напишите функцию `read_note()`. Она запрашивает у пользователя название заметки. Если файл с таким названием существует, функция считывает содержимое файла и выводит его на экран. Если файла не существует, функция выводит сообщение, что заметка не найдена. 
    
Для проверки наличия файла используйте функцию `os.path.isfile` из модуля `os`. Не забудьте импортировать этот модуль.

### Шаг 5. Напишите функцию, которая редактирует заметку
Напишите функцию `edit_note()`. Она запрашивает у пользователя название заметки. Если файл с введенным именем существует, функция считывает и выводит содержимое файла, запрашивает у пользователя новый текст заметки и обновляет содержимое файла. Если файла не существует, она выводит сообщение, что заметка не найдена.

### Шаг 6. Напишите функцию, которая удаляет заметку
Напишите функцию `delete_note()`. Она запрашивает у пользователя название заметки. Если файл с введенным именем существует, функция удаляет файл. Если файла не существует, она выводит сообщение, что заметка не найдена.

Чтобы удалить файл, используйте функцию `os.remove` из модуля `os`.

### Шаг 7. Напишите функцию, которая управляет работой приложения
Напишите функцию `main()`. Она содержит основной цикл программы. Функция отображает меню с вариантами действий с заметками, которые пользователь может выбрать. Затем функция выполняет действие, которое выбрал пользователь.

### Шаг 8. Напишите функцию, которая выводит все заметки пользователя
Задайте функцию `display_notes()` , которая будет выводить все заметки. 
    
Функцию можно реализовать следующим образом: 
1. Примените `list comprehension`, чтобы создать список всех заметок. Для этого можно использовать такую команду, которая создает список из всех файлов текущей рабочей директории с расширением `.txt`.
2. Запустите цикл `for` или генератор списков, который проходится по списку заметок и выдает их по очереди.

    <details>
        <summary><strong>Как это сделать</strong></summary>
        
    Изучите пример кода генератора списков.
    
    ```python
    notes = [note for note in os.listdir() if note.endswith(".txt")]
    ```
    
    </details>

3. Настройте функцию `display_notes()` так, чтобы она выводила заметки в порядке увеличения их длины, то есть сначала самые короткие, а в конце — самые длинные.

### Шаг 9. Напишите функцию, которая добавляет сортировку для заметок
1. Задайте функцию `display_sorted_notes()`, которая выводит заметки в нужном порядке. Как и в предыдущей задаче, функция создает список всех заметок.
2. Примените функцию `sorted`. Передайте ей лямбда-функцию в качестве параметра `key` для сортировки списка по длине заметки. Настройте функцию так, чтобы она выводила заметки в порядке от самой длинной до самой короткой.
3. Добавьте вызов функции `display_sorted_notes()` в основную функцию `main()`. Тогда пользователь сможет выбрать показ заметок в упорядоченном виде как одно из действий.

### Шаг 10. Сделайте приложение отказоустойчивым
Приложение должно обрабатывать любой пользовательский ввод и не выдавать при этом ошибку. Для этого оберните функции в блоки `try-except`:
1. Когда вы задаете функцию, на следующей строчке напишите `try`, затем (с отступом) — код функции.
2. Ниже напишите `except` и команды, которые приложение исполнит, если появится ошибка.
3. Оберните в блок `try-except` каждую функцию приложения.

<details>
    <summary><strong>Как это сделать</strong></summary>
    
Изучите пример использования блока `try-except` для функции `build_note(note_text, note_name)`.

```python
def build_note(note_text, note_name):
    try:
        with open(f"{note_name}.txt", "w") as file:
            file.write(note_text)
        print(f"Заметка {note_name} создана.")
    except:
        print("Произошла ошибка.")

```
    
</details>
